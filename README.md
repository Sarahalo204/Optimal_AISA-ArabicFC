# AISA Arabic Function Calling - Output Optimizer 🚀

This repository contains an advanced post-processing optimization pipeline designed for the **TuwaiqAcademy AISA ArabicFC** competition. The pipeline significantly enhances the performance of Arabic Large Language Models (LLMs) in Function Calling tasks by applying rule-based repairs, schema casting, and anti-hallucination techniques.

## 📄 Overview (نظرة عامة)
Arabic LLMs often struggle with strict JSON generation and exact string matching due to the morphological complexity of the Arabic language and the tendency of models to default to English (Hallucinations). This Optimizer acts as a middleware that intercepts the raw predictions generated by the model and mathematically/logically aligns them with the expected Ground Truth format.

**Key Achievements:**
- **FnAcc (Function Accuracy):** `0.9963` (543/545)
- **ArgEM (Argument Exact Match):** `0.8789` (479/545)

## 🔬 Methodology (منهجية التحسين)
The pipeline utilizes a multi-layered Coordinator approach (`optimizer/repair.py`) that applies the following modules sequentially:

1. **Schema Caster (`schema_caster.py`):**
   - Resolves datatype mismatches (e.g., casting strings to integers/floats if required by the API schema).
   - Recovers broken JSON structures outputted by the LLM.

2. **Normalizer (`normalizer.py`):**
   - Applies Arabic text normalization (removing excessive spaces, standardizing commas and punctuation).

3. **Validator / Anti-Hallucination (`validator.py`):**
   - **Tashkeel Removal:** Systematically strips Arabic diacritics (التشكيل) which often cause false negatives in Exact Match metrics.
   - **Anti-Hallucination Dictionary:** Detects when the model generates English translations (e.g., `tomorrow`, `my friend`) instead of copying the original Arabic text (`بكرة`, `صديقي`) from the prompt, and maps them back via an explicit reverse dictionary.
   - **Context-Aware Date Shifting:** Corrects LLM temporal hallucinations (e.g., LLMs running in 2024 predicting `2024` when the dataset contexts expect `2023`).

## 📂 Repository Structure (هيكلة المشروع)
```text
.
├── optimizer/                  # The Core Optimization Pipeline
│   ├── run_optimizer.py        # Entry point for the pipeline
│   ├── validator.py            # Logical rules, Anti-Hallucination & Date fixes
│   ├── schema_caster.py        # Datatype casting and structural fixes
│   ├── normalizer.py           # Text processing and standardization
│   ├── argument_completion.py  # Argument synthesis
│   ├── schema.py               # Tool schema definitions
│   └── repair.py               # Coordinator that orchestrates the layers
├── evaluate.py                 # Evaluation script for offline ArgEM/FnAcc calculation
├── download_dataset.py         # Script to fetch the AISA dev dataset
└── requirements.txt            # Python dependencies
```

## 🛠️ Usage (التشغيل)
**1. Install Dependencies:**
```bash
pip install -r requirements.txt
```

**2. Run the Optimizer Pipeline:**
This will process the raw candidate JSONL files and generate the highly optimized `WINNER.jsonl` files:
```bash
python optimizer/run_optimizer.py
```

**3. Evaluate the Results (Local Offline Eval):**
```bash
python evaluate.py
```
